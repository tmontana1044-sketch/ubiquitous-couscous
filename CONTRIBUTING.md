Contributing & paid-work flow

Thank you for considering contributing or commissioning paid work.

Labels to use (create these via GitHub UI or gh/REST API):
- paid-feature
- sponsor
- bounty
- help wanted

Paid feature workflow (recommended)

1. User opens an issue using the Paid feature request template (.github/ISSUE_TEMPLATE/paid-feature-request.md).
2. Maintainer responds and moves the issue to a private negotiation channel (email / direct message) to exchange scope and payment details.
3. Upon agreement, create a fork or branch and a hidden milestone; after payment, merge or deliver the artifact.

If you'd like, I can add a GitHub Actions workflow or issue automation (via Probot/GitHub Apps) to help track paid work.
